# StepUp backend

PostgreSQL + Express API for real company authentication and job publishing.

1. Create a PostgreSQL database named `stepup`.
2. Run `schema.sql` against it.
3. Copy `.env.example` to `.env` and set `DATABASE_URL` and a strong `JWT_SECRET`.
4. Run `npm install`.
5. Run `npm start`.
6. Serve `FRONTEND` with Live Server.

No demo/seed company or job records are created.
